## 简介

MyResume 是一个轻量级的 Web 简历生成器，采用单文件架构（HTML + CSS + JavaScript），无需后端服务，打开浏览器即可使用。支持实时编辑、多模板切换、证件照上传、PDF 下载及链接分享，帮助你高效制作一份专业美观的个人简历。

---

## 功能特性

| 功能 | 说明 |
|---|---|
| **实时预览** | 左侧编辑、右侧即时渲染，所见即所得 |
| **多套模板** | 内置 6 款风格模板：经典黑白、商务蓝、设计师彩、学术风、现代简约、活力撞色 |
| **证件照上传** | 支持上传 JPG/PNG 证件照（≤5MB），模板自适应展示 |
| **PDF 导出** | 基于 html2pdf.js，一键生成 A4 格式 PDF 文件 |
| **链接分享** | 将简历数据编码至 URL Hash，复制链接即可分享完整简历 |
| **模块化编辑** | 个人信息、个人简介、工作经历、教育背景、专业技能、项目经历，折叠式面板管理 |
| **打印优化** | 内置 `@media print` 样式，支持 `Ctrl+P` 直接打印 |
| **纯前端部署** | 零后端依赖，单个 HTML 文件即可运行 |
| **多端适应页面** | 面向移动端和PC端都可流畅浏览操作 |
